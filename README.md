# Подработка

Android-приложение и локальный backend для учебного проекта.

## Запуск

На компьютере должны быть установлены Android Studio, Android SDK с Android Emulator и актуальный Docker Desktop с Docker Compose. Docker Desktop должен быть запущен (можно включить автозапуск при входе в Windows). Запустите эмулятор, откройте проект в Android Studio и нажмите **Run** для приложения. Перед сборкой Gradle автоматически запускает Docker Compose, ждёт готовности MySQL и REST API и настраивает ADB-перенаправление порта на подключённый Android Emulator.

При первом запуске Docker скачает необходимые образы и Maven-зависимости. Для этого нужен интернет. После успешного старта приложения можно зарегистрировать аккаунт или выбрать вход гостем. Если Docker Desktop не установлен или не запущен, Gradle покажет ошибку запуска локальных сервисов.

## Локальные данные

Файлы MySQL сохраняются в `.local/mysql/` в папке проекта. Эта директория исключена из Git: у каждого участника своя база и свои регистрации. SQL-миграции находятся в `backend/src/main/resources/db/migration/` и автоматически создают структуру таблиц. MySQL доступен внутри Docker Compose только backend-сервису, а API опубликован на localhost и доступен эмулятору через ADB-перенаправление. Чтобы открыть консоль MySQL вручную, выполните `docker compose exec mysql mysql -u parttime_app -p parttime` и введите пароль `course-app`.

Остановка контейнеров из корня проекта:

```powershell
docker compose down
```

Команда останавливает сервисы, но оставляет локальные данные. Чтобы очистить свою базу, сначала остановите контейнеры, затем удалите папку `.local/mysql/`; следующая сборка создаст новую пустую базу.

## Состав

- `app/` — Android-клиент на Java.
- `backend/` — REST API на Spring Boot.
- `compose.yaml` — MySQL, API и локальная папка данных.
- `app/build.gradle.kts` — автоматический запуск Compose перед Android-сборкой.
